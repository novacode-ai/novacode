# ◇ Nova Code

> **🚀 COMING SOON: The ultimate autonomous Agentic AI CLI ecosystem.**

Nova Code is a next-generation, terminal-based AI software engineer. It is designed to run completely autonomously within your workspace—capable of reading files, executing bash commands, and writing code in a continuous agentic loop.

## 🔥 Features (In Development)

- **True Agentic Loop:** Nova Code doesn't just chat. It thinks, runs system commands (via MCP tools), reads outputs, and iteratively solves complex software bugs.
- **Cloud & Local Model Support:** Seamlessly swap between powerful cloud APIs (OpenAI, Anthropic) and completely free, private local models (Ollama, LMStudio) using our dynamic provider router.
- **Native Responsive UI:** A gorgeously designed terminal UI featuring live animated tool spinners, code syntax highlighting, and native tab-autocomplete.
